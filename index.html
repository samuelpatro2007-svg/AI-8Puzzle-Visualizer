What is the 8-Puzzle?

The 8-puzzle is a 3 × 3 board with eight numbered tiles and one blank square. A tile next to the blank can slide into it. The task is to transform a given initial state into a goal state using as few moves as possible.

It is a classic problem in Artificial Intelligence because it is small enough to visualise, yet large enough that blind search is visibly wasteful. That makes it ideal for comparing uninformed and informed (heuristic) search.

As a state-space search problem

StateAn arrangement of the 8 tiles and the blank on the 3 × 3 grid
Initial stateAny arrangement entered by the user or generated at random
ActionsMove the blank Up, Down, Left or Right (2–4 legal moves per state)
Transition modelSwap the blank with the tile in the chosen direction
Goal testThe current state equals the goal state
Path cost1 per move, so path cost = number of moves

Solvability: sliding a tile never changes the parity of the number of inversions, so a goal is reachable only if the start and goal have the same inversion parity. The solver checks this before searching.
